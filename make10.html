PYTHON · CS50P FINAL PROJECT

Make 10

A terminal-based arithmetic game where four random digits must be used in the exact order provided, with basic arithmetic operations and at most one pair of parentheses, to produce exactly 10.

01 · GAME LOOP

Small rules, enough logic to make the implementation interesting.

The game generates four random single-digit numbers from 0–9. A player enters an arithmetic expression using all four digits in the same order. The expression may use +, -, *, / and at most one pair of parentheses, and it must evaluate to exactly 10.

01Generate

Produce four random digits for the round.

02Validate

Check digit order and the allowed expression format.

03Evaluate

Evaluate the accepted arithmetic expression and compare it with 10.

04Assist

Allow hint to search for a valid solution and quit to exit.

02 · IMPLEMENTATION

Functions are separated around the game’s responsibilities.

The submitted project README describes the implementation as a set of top-level functions in project.py, matching the CS50P final-project structure.

generate_numbers()Creates the four random digits.
evaluate_expression(expr)Evaluates an accepted arithmetic expression and handles failures such as division by zero.
is_valid_expression(expr, numbers)Checks that the required digits appear in the correct order and restricts parentheses.
find_solution(numbers)Tries combinations of operations and parentheses to find an expression that reaches 10.
play_game()Controls input, output, hints, validation and the repeated game loop.

The project uses Python’s eval() for arithmetic evaluation after restricting the accepted expression format. The solver uses brute-force search because the search space is small enough for this game.

03 · TESTING

Unit tests cover the parts most likely to break the rules.

test_project.py contains pytest coverage for number generation, expression evaluation and expression validation. The project has no external Python dependencies, so its requirements.txt is empty.

pytest random number constraints evaluation / division errors digit-order validation
04 · WHY IT IS HERE

A small project, shown for specific evidence.

I do not present Make 10 as a large software system. It belongs in this portfolio because it provides a compact example of Python fundamentals, function decomposition, input validation, basic algorithmic search, error handling and automated testing.
