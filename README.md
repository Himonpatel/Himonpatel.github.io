# Himon Patel Portfolio V20

V20 builds on V19 and adds the ICAICS-26 material as an honest development milestone for Project Atlas.

## What changed
- Added an **Activities & presentations** section on the homepage.
- Added the ICAICS-26 conference photo as a real activity, separate from Work Experience.
- Added an **Early public presentation** section to the Atlas case study with the poster photo and conference photo.
- Framed the conference as an early communication/product-learning checkpoint, **not as an award or validation**.
- Updated Atlas navigation and section numbering to include this evolution step.
- Refined the Work Experience heading so projects remain clearly separate from employment.
